# FF14 魔光键影活动 · 屏幕文字识别自动打字辅助工具

针对《最终幻想 XIV》(FFXIV)「魔光键影」活动做的读屏打字工具。

活动玩法：怪身上显示中文词条，玩家要在输入框里打出对应内容才能消灭怪物，
词条会变化、数量多、节奏快。

本工具自动完成：**截屏 → OCR 识别怪名字牌 → 匹配词条库 → 直接注入汉字 → 回车发送 → 验证怪是否被消灭**。

---

## 特性

- **无需 pip 安装**：只用 Python 标准库 + Windows 自带 OCR（`Windows.Media.Ocr`）
- **词条库来自社区**：`词条总表.tsv` 引用自社区整理的《魔光键影词库》（见文末致谢）
- **不经过输入法**：用 `SendInput` + `KEYEVENTF_UNICODE` 直接把汉字送进游戏输入框，
  规避输入法候选排序、多音字、拼音注错等一堆问题
- **词条库纠错**：活动词条做模糊匹配，OCR 读错字也能纠正，纠正结果自动记忆
- **全自动验证**：打完看怪是否消失，没死就换一种读音/词条重试
- **防掉线**：每 N 次发送 或 每 N 秒自动敲一个字符并删掉（不发送内容）
- **标点兼容**：识别时忽略标点，输入时保留标点（半角自动转全角）
- **自带 OCR 服务**：`bin/ocr_host.exe` 已编译，源码在 `src/ocr_host.cs`

## 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（64 位） |
| Python | 3.x（**唯一需要安装的东西**） |
| OCR | 系统自带中文 OCR（中文版 Windows 默认有） |
| 游戏 | 显示模式为「窗口化」或「窗口化全屏」，独占全屏抓不到画面 |

### 安装 Python

1. 打开 <https://www.python.org/downloads/windows/>
2. 点 `Latest Python 3 Release`
3. 在 Files 表里下载 `Windows installer (64-bit)`
4. **安装界面最底部勾选 `Add python.exe to PATH`**（默认不勾，漏了会一闪就退）
5. 装完验证：`cmd` 里敲 `python --version`

## 使用步骤

1. **建议双击 `管理员启动.bat`**（会弹 UAC，点「是」）
   —— 游戏一般都是管理员权限运行，普通 `启动.bat` 发的按键会被系统拦掉
2. 顶部下拉框选游戏窗口
3. 点「试识别一次」，日志里必须出现 `行数=12`（大于 0）和怪名字
   - `行数=0` → 把「OCR倍率」调成 `2.0` 再试
4. 进入活动画面后框两个区域：
   - 「🖱 拖拽框选区域」→ 只框怪名字那条横带
   - 「🖱 框选输入框」→ 框住游戏里能打字的输入框
5. 点「▶ 启动」

快捷键：`F8` 暂停/继续（暂停时窗口会回来），`F9` 停止。

## 工作原理

```
GDI 截屏(CopyFromScreen)          →  指定区域的图片
        ↓
ocr_host.exe + Windows.Media.Ocr  →  文字行 + 坐标
        ↓
词条库模糊匹配(词条总表.tsv)        →  确定要打的词
        ↓
SendInput + KEYEVENTF_UNICODE     →  汉字直接进输入框
        ↓
Enter 发送 → 再识别一次验证怪是否消失
```

### 为什么不用拼音

输入法路线要经过「组字 → 候选面板 → 选字 → 上屏」，
候选排序常被系统高频词压过，多音字和拼音注错也会导致失败。
Unicode 直输把这一整段跳过：输入法上屏时最终也是发一个字符给窗口，我们直接自己发。

## 配置文件

`config.json` 保存所有参数，常用的几个：

| 参数 | 默认 | 说明 |
|---|---|---|
| `ocr_scale` | 1.0 | OCR 放大倍率，**辉光字体建议 2.0** |
| `cooldown` | 0.5 | 两次输入之间的最短间隔（秒） |
| `anti_afk` | true | 防掉线开关 |
| `anti_afk_seconds` | 10 | 每满 N 秒活动一次 |
| `anti_afk_every_sends` | 7 | 每发送 N 次也活动一次 |
| `keep_punct` | true | 打字时保留标点 |
| `open_with_enter` | true | 打字前先按 Enter 激活输入行（FF14 需要） |

## 词条库

`词条总表.tsv`：`词条<TAB>拼音<TAB>词频`。

活动更新后直接替换这个文件即可，不需要改代码。
`data/learned.json` 会自动记录 OCR 误读纠正。

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 双击一闪就退 | 没装 Python 或没勾 `Add python.exe to PATH` |
| `python` 弹出微软商店 | 那是系统自带的假 python，去「设置 → 应用 → 应用执行别名」关掉再装 |
| 一直提示"打不进去" | 游戏不在前台，先点一下游戏画面；或用 `管理员启动.bat` |
| 试识别 `行数=0` | OCR 倍率太低（改 2.0），或框的位置是空的 |
| 截图全黑 | 游戏是独占全屏，改成窗口化 |
| 框内读出玩家名字 | 输入框区域框错了，在活动画面里重框 |
