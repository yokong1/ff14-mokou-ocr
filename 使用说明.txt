识别打怪助手 · 使用说明
==================================================

一、环境要求（第一次用先看这里）
--------------------------------------------------
【1】Python 3 —— 唯一需要安装的东西，也是唯一容易出错的地方

    ★ 一般电脑都不带 Python，Windows 系统不自带，必须自己下载安装。

    下载地址：
    https://www.python.org/downloads/windows/

    打开后按这三步走：
    ① 点 "Latest Python 3 Release - Python 3.x.x"
       （不要点 "Python install manager" 那一条）
    ② 页面拉到最下面的 Files 表格，点
       "Windows installer (64-bit)"
       （不要下 32-bit / embeddable / zip 版本）
    ③ 双击下载好的 exe 开始安装

    ★★ 安装时特别重要的一步 ★★
    安装器第一个界面的【最底部】有一行小方框：

         [ ] Add python.exe to PATH

    这个框默认是【不勾】的，必须手动点一下变成 [√]，
    然后再点 "Install Now"

    不勾会怎样（非常常见）：
    · 敲 python 提示"不是内部或外部命令"
    · 或者自动打开微软应用商店（那是系统自带的假 python，用不了）
    · 本工具双击后一闪就退

    装完自己验证一下：
    Win+R → 输入 cmd → 回车 → 敲：  python --version
    · 显示 Python 3.xx.x  → 成功，可以往下走了
    · 报错 / 弹出应用商店 → PATH 没勾，重新运行安装包
                             → 选 Modify → 勾上
                               "Add Python to environment variables"

    好消息：装好 Python 就够，不需要 pip install 任何东西，
           工具只用 Python 标准库 + 自带的 ocr_host.exe

【2】中文 OCR
    中文版 Windows 默认自带，99% 的人不用管。
    英文版 Windows 需要装「中文(简体)」语言包里的 OCR 组件。

【3】游戏显示模式
    用「窗口化」或「窗口化全屏」。
    独占全屏抓不到画面，工具会瞎。

二、使用步骤
--------------------------------------------------
1) 双击 启动.bat
   如果游戏是以管理员身份运行的，请改双击 管理员启动.bat

2) 最上面下拉框选游戏窗口
   看不到就点「刷新窗口」

3) 先点「试识别一次」，确认能看见字
   日志里必须出现 "行数=N"（N 大于 0），下面跟着怪名字
   · 行数是 0  → 把「OCR倍率」调成 2.0，再试
   · 还是 0    → 框的位置是空的，重新框区域

4) 进入游戏里那个活动画面后，再框两个地方
   ·「🖱 拖拽框选区域」→ 只框怪名字出现的那一条横带
   ·「🖱 框选输入框」  → 框住游戏里能打字的那条输入框
   框的时候会出现半透明遮罩，能透过它看见游戏画面

5) 点「▶ 启动」
   F8 = 暂停（窗口会回来，可以看日志），再按 F8 继续
   F9 = 停止

三、怎么判断成功了
--------------------------------------------------
日志里出现这些就是通了：
    框内='琪里耶'                      ← 字已经进游戏输入框
    打掉了 琪里耶 (提交方式=unicode)    ← 整个世界清净了
    防掉线: 已活动一次                  ← 挂机保护在工作

四、常见问题
--------------------------------------------------
· 双击一闪就退
  没装 Python，或者装的时候没勾 Add python.exe to PATH（见上面【1】）

· cmd 里敲 python 弹出微软应用商店
  那是 Windows 自带的假 python，不算装好。
  去「设置 → 应用 → 高级应用设置 → 应用执行别名」，
  把 python.exe / python3.exe 两个开关关掉，再重新装 Python。

· 一直提示"这一步打不进去"
  按键没进游戏。先点一下游戏画面让它到最前面；
  还不行就用 管理员启动.bat

· 试识别 行数=0
  OCR 倍率太低（这套游戏的辉光字体 1.0 读不出来），调成 2.0

· 框内读出来是玩家名字
  输入框区域框错了。要在活动画面里重新框那个输入框

· 截图是黑的
  游戏是独占全屏，改成窗口化

· 打字重复两遍
  老版本的 bug，用最新版即可

五、说明与注意
--------------------------------------------------
· 工具只做两件事：截屏识别文字 + 模拟键盘输入
  不读游戏内存、不改游戏文件
· 程序未签名，杀毒软件可能误报，加白名单即可
· 防掉线功能: 每 7 次发送 或 每 10 秒(取先到的)活动一次，只敲一下并删掉，不会发送内容
· 间隔时间、暂停阈值等参数都在 config.json 里改
