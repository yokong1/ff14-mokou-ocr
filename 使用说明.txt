ff14 mokou ocr · 0.9.2
=======================

一、运行环境

1. Windows 10 / 11，64 位。
2. 安装完整的 Python 3.x（64 位），保留 Tcl/Tk（tcl/tk and IDLE）。
3. 需要 Windows 的简体中文 OCR 语言组件。
4. 无需 pip install，无需 Pillow 等第三方 Python 包。
5. 游戏建议使用窗口化或无边框窗口化，并保持画面可见。

二、下载与启动

1. 完整解压项目文件夹，不要只下载 app.py，也不要在压缩包内直接运行。
2. 保留 core、bin、launcher.ps1、词条总表.tsv 及启动批处理文件。
3. 推荐双击「管理员启动.bat」，在系统权限提示中选择「是」。
   普通权限入口「启动.bat」也继续保留。
4. 确认工具标题显示 ff14 mokou ocr · 0.9.2。

三、使用步骤

1. 点击「刷新窗口」，选择游戏窗口。最小化的游戏请先恢复显示。
2. 怪名区域：框住怪物名字可能出现的完整范围，尽量排除无关画面。
3. 输入框区域：只框文本输入区域，不要包含左边输入法的「中」。
4. 鼠标放在区域标签上可查看说明。
5. 点击「试识别一次（不按键）」查看结果，或先勾选模拟模式。
6. F8 开始 / 暂停 / 继续，F9 停止。模拟模式不会发送按键。
7. 移动、缩放游戏窗口或改变分辨率后，重新框选区域。

四、输入方式

沿用原版流程：Enter 激活输入框 → Unicode 输入汉字 → Enter 发送。
正常优先 Unicode，保留原版的兼容回退和失败重试。
输入框 OCR 采用原版宽松判断，不要求识别文字逐字相等。

五、本次主要更新

- 改善小字、彩色底、蓝色辉光和较暗灰字的漏读。
- 修复 13～14 字 Boss 词被长度上限跳过的问题。
- 修正缩小扫描和输入区域排除的坐标，定期复扫完整范围。
- 减少重复 OCR 和词库遍历，记住有效识别方式。
- 增加 OCR 通信请求锁和重复启动检查，修复并发稳定性问题。
- 精简不需要的按钮，补充选区说明，预览不再依赖 Pillow。

六、问题排查

管理员启动日志：launch-admin.log
普通启动日志：launch.log

找不到 Python / Tkinter：安装包含 Tcl/Tk 的完整 Python 3.x（64 位）。
没有中文 OCR：检查 Windows 简体中文语言中的 OCR 组件。
识别不到文字：先检查目标窗口、画面是否可见和怪名选区，再试识别一次。
日志可查看有效倍率、OCR 次数和耗时；必要时调整 OCR 倍率。

详细更新与验证范围见 README.md 和 CHANGELOG.md。
